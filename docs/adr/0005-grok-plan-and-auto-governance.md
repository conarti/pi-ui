# File-backed Plan Mode and classifier-backed Auto governance

Scraping numbered steps from read-only assistant replies coupled `Plan` review to fragile chat formatting and prevented iterative Markdown editing, while flat mutating-call prompts (`Auto-Safe`) interrupted routine workspace work. `@conarti/pi-ui` adopts Grok's three-posture `Session Mode` model (`Always-approve` by default, `Plan`, and `Auto`): `Plan` mode persists a 4-state lifecycle (`Inactive`, `Pending`, `Active`, `ExitPending`), gates file writes strictly to the session `plan.md` file while preserving the underlying permission posture for non-edit tools, and opens `Plan Approval` via `enter_plan_mode` / `exit_plan_mode`; `Auto` mode combines fast read-only local checks, `deny > ask > allow` permission rules, and a configurable LLM safety classifier that raises `Permission Prompt` (with scoped per-project `Always allow` / `Never allow` grants and inline rejection notes) only for risky or protected operations.
