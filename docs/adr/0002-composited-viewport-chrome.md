# Composited viewport chrome with full-width ScrollView

Mounting `Sticky Prompt` as a `VStack` row above `ScrollView` changes `viewportHeight` mid-scroll (causing transcript jumps), and placing `Outline Rail` to the right of `ScrollView` in an `HStack` moves `ScrollView`'s native scrollbar (`box.rect.x + box.rect.width - 1`) to the left of `Outline Rail` while breaking full-width Kitty image cropping. Instead, `ScrollView` spans the full viewport width and height so its native scrollbar stays at the rightmost terminal column, transcript content reserves a stable right margin for the rail, `Outline Rail` composites immediately to the left of the scrollbar column, and `Sticky Prompt` composites in-place over the top rows of the scrollback viewport with row-by-row push displacement when the next `Turn` approaches.
