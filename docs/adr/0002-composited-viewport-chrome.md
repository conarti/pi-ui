# Composited viewport chrome with full-width ScrollView

Mounting `Sticky Prompt` dynamically above `ScrollView` changes `viewportHeight` mid-scroll (causing transcript jumps), placing `Outline Rail` beside `ScrollView` in an `HStack` shifts layout columns, and showing `ScrollView`'s native blocky scrollbar causes a 1-column width jump once scrollback overflows. Instead, only the fixed 3-row session header mounts statically above `ScrollView` (keeping `viewportHeight` constant during scroll), `ScrollView` spans 100% of the viewport width over symmetric 2-column outer canvas margins (`x = 2 .. width - 3`) with the native scrollbar and host jump banner suppressed, `Outline Rail` composites directly inside the right 2-column margin (`width - 2 .. width - 1`, preserving underlying surface backgrounds) alongside centered `▲`/`▼` scroll indicators, and `Sticky Prompt` composites in-place over the top rows of `ScrollView` (`y = 3`) with row-by-row push displacement when the next `Turn` approaches.
